Privacy

The short version

SymbolSweep is a local-only desktop app. We collect no data.

What stays on your machine

Everything. SymbolSweep scans your filesystem for developer artifacts—build caches, derived data, package manager directories—and displays the results locally. No scan data, file paths, directory names, or disk metrics ever leave your Mac.

What it accesses

SymbolSweep reads only the directories it needs to measure and clean:

  • Xcode DerivedData and Archives
  • node_modules, .pnpm-store, and package manager caches
  • Rust target directories
  • CocoaPods and Carthage build folders
  • Swift Package Manager caches
  • macOS symbol caches (coresymbolicationd)

It does not access your documents, photos, mail, browser data, or any directories outside its scan scope. Deletes always go to macOS Trash first.

Network requests

SymbolSweep makes exactly two kinds of network requests, and neither carries your scan data:

  • License activation. When you activate SymbolSweep, and every 30 days afterward to re-validate your license, the app contacts Lemon Squeezy’s license API, sending your license key and a machine identifier (your Mac’s IOPlatformUUID). Nothing else.
  • Update check. The app contacts our update server, sending only the current app version, to fetch the release manifest.

No scan results, file paths, or disk metrics are ever transmitted. It does not phone home, upload telemetry, or communicate with any other server.

Analytics

None. No cookies, no tracking pixels, no analytics service—not in the app, not on this website.

Third parties

We don’t share data with third parties because we don’t have any data to share.
